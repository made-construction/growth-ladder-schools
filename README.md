# مدارس سُلّم النمو | Growth Ladder Schools – دراسة الجدوى التفاعلية

> نرتقي بالعلم، وننمو بالمستقبل

موقع تفاعلي مستقل يعرض الدراسة الفنية والهندسية لمدرسة أهلية بالرياض (تمهيدي + ابتدائي، قسم بنين وقسم بنات)، بتصنيف «مجمع تعليمي»، في **مبنى قائم يُستأجر ويُؤهَّل**. هذه **نسخة غير مالية**: حُذفت الدراسة المالية بالكامل.

- **HTML + CSS + JavaScript فقط:** بلا خوادم ولا قواعد بيانات ولا اشتراكات.
- **حسابات حقيقية:** معادلات النسخة غير المالية من ملف الدراسة (870 معادلة) مترجمة آلياً ومطابقة لإعادة حساب LibreOffice.
- **اشتراطات المباني التعليمية:** 71 متطلباً من النصوص الرسمية، مع الجهة والمرجع والطبيعة والانطباق.
- **معايير المباني التعليمية:** أداة لفحص المباني المرشحة للاستئجار ومقارنتها، بنتيجة استرشادية مع الأسباب ومراجعها.
- **الهوية 1.3:** خط المراعي وألوان سُلّم النمو وشعاراتها الرسمية.

## الأقسام (مرتبة حسب أولوية القرار)
**التعريف بالمشروع**
1. الرئيسية
2. الملخص التنفيذي

**المتطلبات النظامية والمبنى**
3. اشتراطات المباني التعليمية
4. معايير المباني التعليمية

**الدراسة الفنية**
5. الدراسة الفنية والهندسية (مرجعية – خيار المبنى الجديد السابق)
6. الطاقة الاستيعابية

**القرار والتنفيذ**
7. المخاطر والافتراضات
8. دراسة السوق والطلب
9. الجدول الزمني للتنفيذ (مرجعي)

**المراجع والهوية**
10. المراجع والاعتمادات
11. الهوية المؤسسية والمراجع البصرية

## التشغيل محلياً
```bash
python -m http.server 8000
```
ثم افتح `http://localhost:8000/`. يمكن أيضاً فتح `index.html` مباشرة.

## تنبيه
الدراسة تقديرية لأغراض القرار المبدئي، **وليست اعتماداً رسمياً أو هندسياً**، وتقييم العقارات استرشادي. المراجع النظامية: اشتراطات المباني التعليمية الخاصة 1447هـ (وزارة البلديات والإسكان)، واللائحة المنظمة للمؤسسات التعليمية الخاصة (وزارة التعليم)، وكود البناء السعودي. القيم المبنية على أكواد دولية تحتاج مطابقة SBC 2024 واعتماد الجهات.

الخطوط: المراعي وOutfit برخصة SIL OFL 1.1.
