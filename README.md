# مدارس سُلّم النمو | Growth Ladder Schools – دراسة الجدوى التفاعلية

> نرتقي بالعلم، وننمو بالمستقبل

موقع تفاعلي مستقل يعرض الدراسة الفنية والهندسية لمدرسة أهلية بالرياض (تمهيدي + ابتدائي، قسم بنين وقسم بنات)، بتصنيف «مجمع تعليمي»، في **مبنى قائم يُستأجر ويُؤهَّل**. هذه **نسخة غير مالية**: حُذفت الدراسة المالية بالكامل.

- **HTML + CSS + JavaScript فقط:** بلا خوادم ولا قواعد بيانات ولا اشتراكات.
- **حسابات حقيقية:** معادلات النسخة غير المالية من ملف الدراسة (870 معادلة) مترجمة آلياً ومطابقة لإعادة حساب LibreOffice.
- **أداة تقييم العقارات المرشحة للاستئجار:** مقارنة عدة عقارات ونتيجة استرشادية لكل منها، مع الأسباب والاشتراطات غير المستوفاة.
- **الهوية 1.3:** خط المراعي وألوان سُلّم النمو وشعاراتها الرسمية.

## الأقسام
1. الرئيسية
2. الملخص التنفيذي
3. دراسة السوق والطلب
4. الدراسة الفنية والهندسية (مرجعية – خيار المبنى الجديد السابق)
5. معايير اختيار وتقييم المبنى المدرسي المستأجر
6. الطاقة الاستيعابية
7. الجدول الزمني للتنفيذ (مرجعي)
8. المخاطر والافتراضات
9. المراجع والاعتمادات
10. الهوية المؤسسية والمراجع البصرية

## التشغيل محلياً
```bash
python -m http.server 8000
```
ثم افتح `http://localhost:8000/`. يمكن أيضاً فتح `index.html` مباشرة.

## تنبيه
الدراسة تقديرية لأغراض القرار المبدئي، **وليست اعتماداً رسمياً أو هندسياً**، وتقييم العقارات استرشادي. المرجع النظامي: اشتراطات المباني التعليمية الخاصة (وزارة البلديات والإسكان) – **لم يُتحقق من أحدث نسخة سارية في هذا التحديث** – وكود البناء السعودي 2024. القيم المبنية على أكواد دولية تحتاج مطابقة SBC 2024 واعتماد الجهات.

الخطوط: المراعي وOutfit برخصة SIL OFL 1.1.
