# مدارس سُلّم النمو | Growth Ladder Schools – دراسة الجدوى التفاعلية

> نرتقي بالعلم، وننمو بالمستقبل

موقع تفاعلي مستقل يعرض الدراسة الفنية والهندسية والجدوى المالية (الإصدار v2) لمدرسة أهلية بالرياض (تمهيدي + ابتدائي، قسم بنين وقسم بنات).

- **HTML + CSS + JavaScript فقط:** بلا خوادم ولا قواعد بيانات ولا اشتراكات، ويعمل من أي متصفح على الكمبيوتر والجوال والتابلت.
- **حسابات حقيقية:** كل معادلات ملف Excel v2 (4,697 معادلة) مترجمة آلياً إلى JavaScript، ومطابقة لإعادة حساب Excel عبر LibreOffice بنسبة 100%. المطابقة مختبرة بالمدخلات الأصلية ومع تعديل المدخلات.
- **تفاعلي:**
  - تعديل 1,104 مدخلات.
  - ثلاثة سيناريوهات.
  - رسوم بيانية تتحدث فوراً.
  - حفظ محلي ونسخ محفوظة، مع تصدير واستيراد.
  - إعادة القيم الأصلية.
  - تصدير PDF.
- **الهوية 1.3:** خط المراعي (Almarai) في كل العناصر، وألوان سُلّم النمو وشعاراتها الرسمية.

## التشغيل محلياً
```bash
python -m http.server 8000
```
ثم افتح `http://localhost:8000/`. يمكن أيضاً فتح `index.html` مباشرة.

## تنبيه
الدراسة تقديرية لأغراض القرار المبدئي، **وليست اعتماداً رسمياً أو هندسياً**. المرجع النظامي الوحيد: اشتراطات المباني التعليمية الخاصة 1447هـ (قرار 4600425374/1) وكود البناء السعودي 2024. القيم المبنية على أكواد دولية تحتاج مطابقة SBC 2024 واعتماد الجهات.

الخطوط: المراعي وOutfit برخصة SIL OFL 1.1.
