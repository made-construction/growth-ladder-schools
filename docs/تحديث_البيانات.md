# كيفية تحديث بيانات الموقع

يُبنى الموقع من ملف Excel مباشرة: كل معادلة في المصنف تُترجم آلياً إلى JavaScript. لذلك يكون تحديث الأرقام بتحديث ملف Excel، ثم إعادة توليد ملف واحد هو `assets/js/model.js`. **لا تعدّل `model.js` يدوياً، ولا تكتب أي رقم محسوب داخل الموقع.**

## المتطلبات (مجانية)
- Python 3.10+ مع المكتبة `openpyxl` (`pip install openpyxl`).
- Node.js 18+ لأداة التحقق.
- LibreOffice لإعادة الحساب المرجعية، مثل التحقق المتبع في المشروع.

## الحالة 1: تغيرت مدخلات أو أرقام في Excel (نسخة v3 مثلاً)
اتبع قواعد `CLAUDE.md` في حزمة المشروع:
- أنشئ نسخة جديدة باسم جديد مثل `…_v3.xlsx`، ولا تعدّل v2.
- سجّل التغييرات في ورقة سجل التعديلات.

ثم من مجلد الموقع:

```bash
python tools/xlsx2js.py "/المسار/الدراسة_الفنية_والهندسية_مدارس_سلم_النمو_v3.xlsx" assets/js/model.js
```

### التحقق (المطلوب صفر فروق)
```bash
soffice --headless --calc --convert-to xlsx --outdir /tmp/recalc "/المسار/…_v3.xlsx"
```
```bash
python tools/export_ref.py "/المسار/…_v3.xlsx" "/tmp/recalc/…_v3.xlsx" /tmp/ref.json
```
```bash
node tools/verify.mjs assets/js/model.js /tmp/ref.json
```
النتيجة المطلوبة: `match=<عدد المعادلات> mismatch=0 errorsInModel=0`. في v2 كانت النتيجة 4,697 من 4,697.

بعدها ارفع التغييرات إلى المستودع، فيتحدث الموقع المنشور خلال دقيقة أو دقيقتين:
```bash
git add -A && git commit -m "تحديث بيانات الدراسة إلى v3" && git push
```

## الحالة 2: أُضيفت أوراق أو تغير ترتيب الصفوف
- **الأوراق تُعرف برقمها في بداية اسمها:** مثل «17» لورقة «17 التوقعات المالية 5 سنوات». تغيير ما بعد الرقم لا يؤثر.
- **ما يعتمد على العناوين مباشرة:** المؤشرات الرئيسية في `assets/js/app.js` تقرأ خلايا محددة، مثل `V('17','L20')` لصافي القيمة الحالية، أو أسماء معرّفة مثل `NM('Cap_Proposed')`.
- **الإجراء:** إذا تغير موضع صف في الأوراق 13 أو 17 أو 18 أو 19 أو 23 أو 24، حدّث العنوان المقابل في `app.js`. الدالتان `core()` و`yearly()` تجمعان معظمها.
- **ما يتحدث تلقائياً:** الجداول الكاملة للأوراق تُعرض آلياً من Excel ولا تحتاج أي تعديل.

## الحالة 3: تحديث اللوحات الهندسية
1. أعد توليد اللوحات بسكربت `03_scripts/draw_v2/draw.py` في نسخة العمل `WORK/`.
2. صدّر كل صفحة صورةً بالأمر التالي:
   ```bash
   pdftocairo -png -r 170 drawings.pdf p
   ```
3. احفظها بصيغة WebP بنفس الأسماء في `assets/drawings/`، مثل `A-01_site_plan.webp`، مع نسخة مصغرة تنتهي بـ `_t.webp`.
4. حدّث قيم الرسم في `build6.py` ثم أعد بناء Excel، كما ينص `CLAUDE.md`.

## الحالة 4: تحديث نسخة PDF الجاهزة
افتح الموقع محلياً بالرابط `?print`، أو استخدم زر «تصدير PDF» بالمدخلات الأصلية، ثم احفظ الملف في `downloads/`.

لتشغيل الموقع محلياً:
```bash
python -m http.server 8000
```
ثم افتح `http://localhost:8000/`.

## بنية الملفات
| الملف | الوظيفة |
|---|---|
| `index.html` | هيكل الصفحة |
| `assets/css/style.css` | الهوية والتنسيق: ألوان سُلّم النمو وخط المراعي والطباعة والجوال |

| `assets/js/engine.js` | محرك تقييم معادلات Excel في المتصفح |

| `assets/fonts/` | المراعي وOutfit (رخصة SIL OFL 1.1) |
| `assets/brand/` | شعارات الهوية 1.3 (SVG) |
| `assets/drawings/` | اللوحات التصورية v2 |
| `tools/` | أدوات التوليد والتحقق |
| `docs/` | الأدلة وتقرير المراجعة وسجل التعديلات وقائمة الاعتمادات المطلوبة |

## إضافة دالة Excel جديدة
إذا استخدمت الدراسة دالة غير مدعومة، يتوقف `xlsx2js.py` ويطبع اسمها، أو تفشل أداة التحقق برسالة `$.X is not a function`. أضف الدالة إلى الكائن `$` في `assets/js/engine.js` بنفس سلوك Excel، ثم أعد التحقق.

الدوال المدعومة حالياً: IF، IFERROR، AND، OR، SUM، MAX، MIN، AVERAGE، MEDIAN، COUNT، COUNTA، COUNTIF، COUNTIFS، SUMIF، SUMIFS، INDEX، MATCH، ROUND، ROUNDUP، ROUNDDOWN، INT، ABS، SQRT، N، ISNUMBER، TEXT، NPV، IRR، DATE، YEAR، MONTH، EDATE.
